# 기억력 짝맞추기

카드를 잠깐 보여 준 뒤 뒤집고, 어디에 뭐가 있었는지 기억해서 같은 그림끼리 짝을 맞추는 게임. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나.

- 라운드마다 모든 카드를 잠깐 보여 준다 (다 외웠으면 화면을 눌러 바로 시작)
- 틀리면 1초 감점, 판을 다 비우면 시간이 늘어난다 (한 번도 안 틀리면 더 많이)
- 라운드가 갈수록 카드가 12 → 16 → 20장으로 늘고, 보여 주는 시간이 짧아지고, 비슷한 그림이 섞인다

`index.html` 을 그대로 열면 된다. 판 규칙은 `logic.js`(화면 없이 Node 로 시험할 수 있다: `node test/logic.test.js`), 화면·입력은 `game.js`.
